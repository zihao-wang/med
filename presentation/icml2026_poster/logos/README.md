# Logo Assets

These assets are used by `../poster.tex`.

- `icml.svg` / `icml.png`: official ICML vector logo from `https://icml.cc/static/core/img/ICML-logo.svg`. The ICML 2026 site states that the logo may be used on presentations.
- `squarepoint.svg` / `squarepoint.png`: public Squarepoint Capital logo file from Wikimedia Commons redirect.
- `wayne_state.svg` / `wayne_state.png`: public Wayne State University logo file from Wikimedia Commons redirect.
- `uiuc.svg` / `uiuc.png`: public University of Illinois Urbana-Champaign wordmark file from Wikimedia Commons redirect.
- `hkust.svg` / `hkust.png`: public HKUST symbol SVG from the Wikipedia/Wikimedia upload path.
- `nvidia.svg` / `nvidia.png`: public NVIDIA wordmark file from Wikimedia Commons redirect.
- `nvidia_formal_horizontal.svg` / `nvidia_formal_horizontal.png`: official horizontal NVIDIA logo from NVIDIA's logo and brand guidelines page; the PNG is a Quick Look render used by pdfLaTeX.

- `tsy_capital_original.png` / `tsy_capital.png`: TSY Capital logo supplied by the user from the clipboard image in this Codex thread; `tsy_capital.png` is a trimmed copy used by LaTeX.
